## 二、核心组件规范设计

### 2.1 顶部工具栏 (Header Bar)

- **容器高度**：`44px`，底边带有 `1px solid var(--borderColor-default)`。
- **背景底色**：`var(--canvas-subtle)` (`#161b22`)。
- **主行动按钮（渲染导出）**：
  - 采用 GitHub 标志性 Primary Green：`bgColor-rest: #238636`，`hover: #2ea043`；
  - 尺寸为 `size="medium"`（高度 `32px`，Padding `0 12px`，圆角 `6px`）；
  - 左侧带有 Lucide `Rocket` 或 `Download` 图标，文本采用 `font-medium` 纯白。
- **撤销/重做与辅助工具**：
  - 采用 Primer `Ghost` 按钮：常态无底色，悬停时底色为 `rgba(177, 186, 196, 0.12)`；
  - 禁用状态（不可撤销）透明度降至 `40%`，光标为 `not-allowed`。

---

### 2.2 左侧素材与预设面板 (ActionList & TreeView)

参考 Primer 的 `ActionList` 设计，用于展示资产文件夹、轨道图层与动效预设库：

```
┌────────────────────────────────────────────────────────┐
│ 🔍  搜索素材、预设...                        [ Esc ]  │
├────────────────────────────────────────────────────────┤
│ ▼ 📁 项目媒体库 (Media)                                │
│    🎬 intro_video.mp4                   00:15  [ ⋮ ]   │
│    ♫ upbeat_bgm.mp3                     01:30  [ ⋮ ]   │
│ ▶ 📁 文本预设 (Text Presets)                            │
│ ▶ 📁 转场特效 (Transitions)                             │
└────────────────────────────────────────────────────────┘
```

- **单项高度**：`32px`（紧凑桌面密度），垂直间距 `2px`。
- **圆角**：`4px`（`--radius-small`）。
- **交互状态**：
  - **常态**：背景透明，文字为 `var(--fgColor-default)`；
  - **悬停**：背景 `rgba(110, 118, 129, 0.12)`；
  - **选中**：背景 `rgba(56, 139, 253, 0.15)`，左边缘带有 `2px` 宽度的 `var(--accent-fg)` 激活指示线。

---

### 2.3 中间预览舞台与浮动工具条 (Preview Stage & Floating Toolbar)

- **深邃舞台底色**：舞台周边底色设定为极暗且纯净的 `--preview-stage` (`#05070a`)，避免周围界面光溢出干扰视频对比度判断。
- **画布比例遮幅**：视频主体外侧具备清晰的 `1px` 细白边框（`rgba(255, 255, 255, 0.15)`），明确标识 16:9 / 9:16 的物理裁切边界。
- **浮动工具条 (Floating Toolbar)**：
  - 触发机制：当在预览区选中元素时，浮动于选中框正上方 `8px` 处；
  - 样式：`bg: rgba(22, 27, 34, 0.85)` + `backdrop-filter: blur(12px)`；
  - 边框：`1px solid var(--borderColor-default)`，圆角 `8px`；
  - 包含快捷微调：居中对齐、旋转微调、替换素材、删除。

---

### 2.4 底部多轨时间线 (Multi-Track Timeline)

时间线是界面的核心生产力区域，严格执行 Primer 的高对比度与几何对齐规范：

```
┌───────┬────────────────────────────────────────────────────────────────────────┐
│ 00:00 │ 00:02        00:04        00:06        00:08        00:10              │
├───────┼────────────────────────────────────────────────────────────────────────┤
│ [V1]  │  ┌──────────────┐             ┌─────────────────────┐                  │
│ 👁 🔒 │  │ Clip 1 (绿)  │             │ Clip 2 (绿)         │                  │
│       │  └──────────────┘             └─────────────────────┘                  │
├───────┼────────────────────────────────────────────────────────────────────────┤
│ [A1]  │         ┌──────────────────────────────────────┐                       │
│ 🔊 🔒 │         │ BGM.mp3 (深海蓝波形)                  │                       │
│       │         └──────────────────────────────────────┘                       │
└───────┴────────────────────────────────────────────────────────────────────────┘
```

1. **时间刻度尺 (Ruler)**：
   - 高度 `24px`，背景为 `var(--canvas-subtle)`；
   - 刻度线使用 `var(--borderColor-muted)`，主刻度（以秒为单位）文字采用 `11px --font-mono` 等宽排列；
2. **播放头 (Playhead)**：
   - 颜色：`var(--accent-fg)` (`#2f81f7`)；
   - 顶部倒水滴指针宽度 `12px`，高度 `16px`，带平滑 `2px` 倒角；
   - 下垂垂直参考线为纯净 `1px` 蓝色高亮线，贯穿整个时间线区域；
3. **剪辑片段 (Clip)**：
   - 圆角为 `--radius-small` (`4px`)；
   - 视频轨默认块颜色：底色 `#1f4028`，边框 `1px solid #3fb950`；
   - 选中态：边框加粗至 `2px solid #ffffff`，并出现左右手柄调节滑块；
4. **磁性吸附对齐线 (Snap Guide)**：
   - 当片段边缘接近相邻片段或播放头时触发吸附，出现贯穿的 `1px` 虚线，颜色为 `var(--attention-fg)` (`#d29922`)，并弹出当前偏移量数值气泡。

---

### 2.5 右侧面板：属性检查器与 AI Copilot (Property & AI Inspector)

- **折叠分组 (Collapsible Section)**：
  - 标题高度 `32px`，右侧带平滑旋转的小箭头图标（Chevron）；
  - 底部分隔线使用 `1px solid var(--borderColor-muted)`；
- **数字微调输入框 (Compact Stepper Input)**：
  - 高度 `28px`，圆角 `6px`；
  - 字体：`12px --font-mono`，数字右对齐；
  - 支持直接输入，也支持在标签名上横向拖拽进行数值连续增减（Scrubbable Label）；
- **AI 助手对话组件 (Copilot Chat)**：
  - 输入框常态边框带有细腻的紫色微高光提示（`--copilot-subtle`）；
  - 用户消息气泡：中性深灰底色（`var(--canvas-subtle)`）；
  - AI 回复卡片：左侧带 `2px` 宽度的 Copilot 紫色指示条（`#a371f7`），代码差异区块内嵌等宽预览，底部具备 GitHub 绿色的 **“应用到时间线”** 确认按钮。
